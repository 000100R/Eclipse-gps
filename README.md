# উমা এলো — Kolkata Puja Explorer

### পুজো হোক, পথ চলা হোক।

**by RISHIGATO**

উমা এলো is a Kolkata Durga Puja exploration and navigation app designed to make pandal hopping easier, faster, and more organized.

Instead of manually searching for pandal names, the app uses your location to help discover nearby Puja destinations and navigate between them.

---

## ✨ Features

- 📍 Live GPS-based location
- 🛕 Nearby pandal discovery
- 📏 Nearest-to-farthest pandal sorting
- 🗂️ Pandal category filtering
- 🏛️ Bonedi Bari / Rajbari discovery
- 🗺️ Google Maps and 3D map support
- 🛰️ Standard, Satellite and Hybrid map modes
- 🌍 Leaflet / OpenStreetMap map engine
- 🧭 Turn-by-turn navigation
- ⏱️ Dynamic ETA
- 🔄 Route and off-route updates
- 🚦 Traffic information
- 👁️ Google Street View
- 🚇 Kolkata Metro Guide
- 🤖 Eclipse AI Copilot
- 👥 Friends and Eclipse ID
- 📍 Live location sharing
- 📱 Android APK
- 💻 Browser support
- 📂 Mobile-optimized Pandal Explorer

---

## 🛕 Pandal Explorer

The Pandal Explorer is the core feature of উমা এলো.

It uses your current location to organize nearby Puja destinations by distance, helping you decide where to go next.

### Current dataset

- **645 Kolkata Puja entries**
- **80 Bonedi Bari / Rajbari entries**

The dataset includes public Puja destinations and heritage family celebrations across Kolkata.

---

## 📍 GPS & Nearby Discovery

The app uses live GPS location to:

1. Detect your current position.
2. Find nearby Puja destinations.
3. Calculate distance.
4. Sort destinations by proximity.
5. Help you select a destination.
6. Start navigation.

Location access is required for the location-based discovery features.

## 🧭 Navigation

The navigation system provides:

- Route calculation
- Turn-by-turn guidance
- Live movement tracking
- Dynamic ETA
- Off-route detection
- Route updates
- Arrival detection
- Visual navigation HUD

> Voice navigation may not work reliably on some Android devices because of device-level Android Text-to-Speech differences. Visual navigation continues to work.

---

## 🚇 Kolkata Metro Guide

The app includes a Kolkata Metro guide covering supported metro lines and station information to help plan Puja travel.

---

## 🤖 Eclipse AI Copilot

Eclipse AI Copilot provides an AI-assisted interface for exploring Kolkata Puja destinations and related travel questions.

The Copilot backend runs separately from the Android application so API credentials remain server-side.

---

## 👥 Friends & Eclipse ID

The Friends system provides:

- Privacy-focused Eclipse IDs
- Friend requests
- Friend lists
- Live location sharing
- Online/offline status
- Location visibility controls

Live location sharing is optional.

## 🔐 Permissions & Privacy

The application may require:

- Location permission — for GPS discovery and navigation
- Internet access — for maps, data and online services
- Optional live-location access — for Friends features

The application does not require background location permission for normal use.

Never share private API keys or service credentials.
